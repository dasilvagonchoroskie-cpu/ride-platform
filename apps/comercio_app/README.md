# Fortaleza Move Comércio (4º aplicativo)

Aplicativo para lojas pedirem a coleta e a entrega das próprias encomendas.
Usa o mesmo servidor, banco, login, despacho, motoristas, acompanhamento e
tarifas dos outros aplicativos. Não é marketplace (sem catálogo, carrinho ou
checkout).

Veja `docs/COMERCIO.md` na raiz do repositório para o estado de cada item.

Rodar os testes: `flutter test`. Gerar o APK: workflow `android-comercio.yml`.
